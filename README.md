# 📖 Sobre

Biblioteca de funções matemáticas e aritméticas (operações básicas, teoria dos números, geometria, trigonometria e manipulação de arrays) utilizada para estudar e demonstrar testes de mutação. O projeto inclui uma suíte de testes de alta eficácia construída com Jest e validada via StrykerJS, demonstrando na prática como matar mutantes de código e elevar a qualidade das asserções além da cobertura de código tradicional.

# 📋 Motivo

Trabalho prático da disciplina de Testes de Software (PUC) para demonstrar a diferença entre cobertura de código e eficácia de testes através de Teste de Mutação com StrykerJS e Jest.

# 💻 Como iniciar

### Requisitos

- [Node.js](https://nodejs.org/) >= 18.0.0
- [npm](https://www.npmjs.com/)

### Instalação

1. Clone o repositório:

   ```sh
   git clone https://github.com/BGLuis/operacoes-mutante.git
   ```

2. Entre no diretório do projeto:

   ```sh
   cd operacoes-mutante
   ```

3. Instale as dependências e inicie os testes:

   ```sh
   npm install
   npm test
   ```

4. Para executar a análise de teste de mutação com o StrykerJS:

   ```sh
   npm run stryker
   ```
