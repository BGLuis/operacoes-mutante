# 📖 About

Library of mathematical and arithmetic functions (basic operations, number theory, geometry, trigonometry, and array manipulations) used to study and demonstrate mutation testing. The project includes a high-effectiveness test suite built with Jest and validated via StrykerJS, practically demonstrating how to kill code mutants and raise assertion quality beyond traditional code coverage.

# 📋 Motivation

Practical assignment for the Software Testing course (PUC) to demonstrate the difference between code coverage and test effectiveness through Mutation Testing with StrykerJS and Jest.

# 💻 Getting Started

### Requirements

- [Node.js](https://nodejs.org/) >= 18.0.0
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/BGLuis/operacoes-mutante.git
   ```

2. Enter the project directory:

   ```sh
   cd operacoes-mutante
   ```

3. Install the dependencies and start the tests:

   ```sh
   npm install
   npm test
   ```

4. To run mutation testing with StrykerJS:

   ```sh
   npm run stryker
   ```
